# Security Policy

## Reporting a Vulnerability

If you discover a security issue, please report it privately.

Contact: security@diyalabs.ai

Please do not open a public issue for unpatched vulnerabilities.

## Scope

This repository includes:
- verification logic
- policy enforcement
- exception handling
- decision recording

## Secrets

Do not commit:
- private keys
- tokens
- credentials
- signing keys such as `cosign.key`

## Response

Security reports will be acknowledged within 72 hours.
