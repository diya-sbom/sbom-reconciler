# Diya Verification Record — Stewardship

The Verification Record format is maintained as an open specification.

The goal of the specification is to enable independent verification of artifact integrity across different systems and implementations.

This repository provides a reference implementation, but the format itself is not tied to any single implementation.

Implementations in other languages or systems are encouraged as long as they follow the canonicalization and hashing rules defined in the specification.

Changes to the record format must preserve backward compatibility.

New capabilities should be introduced by adding fields or defining new record versions rather than modifying existing semantics.

The purpose of stewardship is to preserve meaning and interoperability of the format over time.
